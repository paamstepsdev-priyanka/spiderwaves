1. Executive Overview (In Short)

The Problem

Community organizations, mandals, and trusts currently manage members across disconnected spreadsheets, paper registers, standalone desktop accounting (Tally), and WhatsApp groups, causing data loss, lack of tax compliance, and disjointed family records.

The Solution

A unified, configurable, multi-tenant cloud application where each organization has isolated data and branding. Unifies Member Directory, Kutumb Family Trees, Dynamic Custom Member Attributes, Multi-tier Governance, POS Counter Fee Receipts, 80G Donations, Double-Entry Accounting, and Social Feeds.

2.1 Feature Specification: Custom Member Attributes

Allows each organization administrator to create, customize, and manage extra fields in the Member Profile independently, without modifying the core software or database schema.

Required Functionalities & Controls

  • Admin Creation: Admin can create new custom fields with unique field name and user-friendly display label.
  • 7 Supported Field Types: Text, Number, Date, Dropdown, Checkbox, Multi-select, and File Upload.
  • Validation & Settings: Mark fields as Required or Optional, and activate or deactivate fields at any time.
  • Dropdown Options Builder: Admin can define, edit, and reorder options for Dropdown and Multi-select fields.
  • Reordering & Grouping: Admin can set display order and assign fields to profile sections (Personal, Education, Profession, Skills, Emergency Contact, etc.).

Dynamic Form & Profile Integration

  • Automatic Form Rendering: Created active fields automatically render in the Add Member and Edit Member forms.
  • Profile 360 Display: Saved custom values are rendered in designated sections within the Member Profile view.
  • Independent Tenant Isolation: Custom fields belong strictly to the creating organization (organization_id); other organizations are completely unaffected.
  • Data Integrity: Prevents deletion of fields that have populated member data (field can be deactivated instead).

5. Key Workflows in Short
Workflow Step-by-Step Flow (Who does what) Key Rule / Validation
New Member Onboarding Applicant submits online form → Clerk checks docs & proposer → Kendra Secretary verifies → Trustee approves → Member ID & QR Card generated. Proposer must be an active, non-defaulter member.
Custom Member Attributes Setup & Data Entry Admin opens Custom Fields → Defines field name, label, type (Text, Dropdown, Date, File, etc.), section & Required toggle → Adds options if dropdown → System dynamically renders field on Add/Edit Member screens → Member/Staff enters value → Stored in mem_custom_field_values & displayed on Profile. Field names unique per organization; required validations enforced; cannot delete field with active populated member data.
Family (Kutumb) Creation Family Head is chosen → Family Code generated → Relatives linked with relationship (Spouse, Son, Mother) → Visual tree drawn. Exactly 1 Head of Family per unit; biological kinship consistency.
Fee Dues & POS Collection System generates annual demand → Member pays online or at counter → Instant PDF/WhatsApp receipt → Receipt Voucher auto-created in GL. Sequential receipt numbering; no duplicate invoicing for same period.
80G Donation Collection Donor contributes → Fund tagged (Building/Education) → 80G Tax receipt generated with PAN → Posted to GL fund → Exported in Form 10BD. Mandatory PAN for 80G tax benefit; sequential certificate numbers.
Accounting Voucher Approval Accountant prepares voucher (Maker) → Balance checked (ΣDr == ΣCr) → Treasurer reviews & approves (Checker) → Posted & locked. Maker cannot be the Checker; posted vouchers cannot be silently deleted.
Committee Meeting & Minutes Secretary schedules meeting & notice → Roll-call & quorum check → Agenda discussed → Resolutions (Tharav) voted & recorded → Minutes signed. Quorum validation check before voting; official minutes locked.
